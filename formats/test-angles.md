# Test angles

**Family key:** `angles` (always `"test": true`)

## Structure
Anything that is not yet proven: a new hook shape, a new emotion, a pattern found in the viral inbox. Use the same slide mechanics as a proven format, so only one thing changes at a time.

## Why it exists
A batch made only of proven formats stops growing. A few clearly marked tests find the next proven format.

## Fill-in slots
- `"test": true` on the post.
- One sentence in your notes on what you are testing (the angle in `viral/angles.json`).

## Rules
- Tests are a minority of a batch. The planner keeps tests out of the first slots and allows at most 2 in any 5.
- After a test performs, promote it: give it its own format file and drop `test`.
- Pattern reuse is fine. Copying someone else's exact words or images is not.
